# 경쟁 앱 6개 비교표
모바일 UX 디자인 (2026-2학기) 기말 프로젝트  
5조 — 「캠퍼스 야간 귀가 안전 앱」 UX 설계  
작성: 강민재 / 10월 17일(토) 03:20 (알바 끝나고 작성)  

| # | 앱 | 핵심 방식 | 사용자 리뷰에서 자주 나온 불만 |
|---|---|---|---|
| 1 | 앱 A | 실시간 위치 공유 | 배터리 소모가 큼 |
| 2 | 앱 B | 실시간 위치 공유 + 위험 지역 알림 | 위험 지역 알림 오탐이 많음 |
| 3 | 앱 C | 실시간 위치 공유 | '감시받는 느낌'이라는 리뷰 다수 ← 차별점 아이디어 |
| 4 | 앱 D | 실시간 공유 + 긴급 전화 | 버튼이 작아 급할 때 누르기 어려움 |
| 5 | 앱 E | 실시간 위치 공유 | 친구 초대가 번거로움 |
| 6 | 앱 F | 실시간 공유 + 경로 기록 | 개인정보가 걱정됨 |


## 한 줄 정리
6개 앱 모두 '추적형'. 감시받는 느낌과 개인정보 걱정이 공통 불만 → '확인형'으로 가면 차별화 가능.
