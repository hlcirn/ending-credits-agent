# 기획서 (최종) — 「도착했어」 야간 귀가 확인 앱
모바일 UX 디자인 (2026-2학기) 기말 프로젝트  
5조 — 「캠퍼스 야간 귀가 안전 앱」 UX 설계  
최종 수정: 10월 30일(금) 23:30 한도윤  

## 1. 문제
밤늦게 혼자 귀가하는 학생은 불안하지만, 기존 안전 앱은 실시간 위치 추적 방식이라 '감시받는 느낌'이 들어 잘 쓰지 않는다.  

## 2. 핵심 아이디어
계속 위치를 보여주는 대신, 도착했는지만 친구에게 알려준다. — '기존 앱은 모두 추적형, 우리는 확인형'  

## 3. 주요 기능
- 출발할 때 '도착하면 알려줄게' 한 번 누르기
- 도착하면 큰 '도착했어' 버튼 한 번
- 예정 시간이 지나면 친구에게 부드러운 확인 메시지 ('도착했나요?')

## 4. 근거
사용자 인터뷰 5명, 반응 테스트 7명, 경쟁 앱 6개 비교
