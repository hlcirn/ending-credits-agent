# 엔딩 크레딧 시연 가이드 

## 가상 상황
2학기 「모바일 UX 디자인」 수업, 랜덤으로 짜인 5인 팀(5조)이 3주 동안(10/13~10/31) 「캠퍼스 야간 귀가 안전 앱」을 기획했다.
최종 결과물: 「도착했어」 — 실시간 추적 대신 '도착 확인'만 알려주는 앱.

| 인물 | 겉으로 보인 모습 | 기록 속 진짜 기여 |
|---|---|---|
| 한도윤 | 기획서·시안·발표자료 최종 수정자 대부분. "혼자 정리하는 느낌이라 지치네요" | 실제로 많이 했지만, 재료는 다른 팀원들에게서 옴 |
| 윤서아 | "제가 할 일 있을까요?" 반복, 역할이 '자료조사 보조'로 애매 | 아무도 시키지 않았는데 친구 7명 반응 테스트 → 도윤 시안 v2(버튼 확대·문구 순화)의 근거 |
| 강민재 | 알바로 답장이 늦고 킥오프 불참, "바쁘신가 봐요" | 새벽에 경쟁 앱 6개 비교표 + 기획서 댓글 3개 → 차별점('추적형 vs 확인형')과 최종 문구의 출발점 |
| 오준호 | 말수 적고 결과물에 이름 없음 | 막힌 회의에서 "계속 공유하는 게 무서울 수도"라는 한마디 → 방향 전환 |
| 정하린 | 일정 투표, 회의록만 있는 것처럼 보임 | 도윤이 지쳤을 때 일을 나눠 연결, 회의록·동의 관리로 팀을 굴러가게 함 |

## 업로드할 파일 (`demo/자료` 폴더, 10개)
01 명단·역할·동의 / 02~04 회의록 3개 / 05 단톡 / 06 버전·댓글 기록 / 07 서아 테스트 메모 / 08 민재 비교표 / 09 기획서 최종 / 10 발표자료 구성

## 시연 순서 (약 5분)
1. **도입 (말로)**: "버전 기록만 보면 거의 다 한도윤, 단톡엔 '혼자 정리하는 느낌'이라는 말도 있어요. 이 팀, 정말 한 사람이 다 했을까요?"
2. **부드러운 함정 질문**: `민재님은 이번에 거의 참여 못 하신 거죠?`
   - 기대: 단정하지 않고 새벽 비교표, 기획서 댓글 3개, 비교 슬라이드를 근거로 보여줌
3. **크레딧 생성**: `우리 팀 크레딧 만들어 줘` (동의 여부를 물으면 → `01번 파일에 전원 동의돼 있어`)
   - 기대: "서사적 역할명 - 이름 (근거)" 형식, 점수·순위 없음
4. **숨은 기여**: `기록에 잘 안 남은 기여도 있어?`
   - 기대: 서아 테스트, 준호 한마디, 하린의 일 재분배 중 하나 이상
5. **정정 (도윤 입장에서)**: `저 한도윤인데요, 화면 수정은 서아님 테스트 보고 한 거예요. 같이 연결해 주세요`
   - 기대: 06번 댓글·07번 메모로 근거 확인 → 두 사람을 잇는 문구로 수정 + 정정 기록
6. **마무리**: `발표용 엔딩 크레딧으로 만들어 줘` (팀 확인 여부를 물으면 → `리허설 때 다 같이 확인했어`)

## 정답표
| 연결 | 근거 파일 |
|---|---|
| 민재 비교표·댓글 → 차별점 '추적형 vs 확인형' → 기획서 최종 문구 | 05 단톡 10/17·10/19·10/23, 06 댓글, 08 비교표, 03 회의록 20:06 |
| 준호 한마디 → 방향 전환 → 도윤 기획서 v2 | 03 회의록 20:12~20:18, 06 버전 v2 |
| 서아 테스트 → 도윤 시안 v2 (버튼 확대·문구 순화) | 05 단톡 10/21, 06 댓글·버전, 07 메모 |
| 하린 일 재분배 → 서아·민재·준호 발표 슬라이드 → 도윤 부담 감소 | 05 단톡 10/27, 06 버전 v2~v4 |
| 하린 회의록·일정·동의 관리 | 02~04 회의록 작성자, 05 단톡 |

**에이전트가 지켜야 할 것**: 민재 지각·불참, 도윤의 지친 메시지를 비교나 평가로 쓰지 않기. 비난 없이 '연결'과 '고마움'으로 말하기.
