# 엔딩 크레딧 🎬

조별과제가 끝날 때 팀의 작업 기록(Teams 회의·채팅, 공유 폴더 문서)을 읽고, 결과물에 남지 않은 **과정의 기여와 서로의 연결**까지 영화 엔딩 크레딧처럼 이름을 올려 주는 Microsoft Copilot Studio 에이전트입니다.

> 점수·순위·기여 비중을 매기는 동료평가가 아니라, **비교 대신 감사**를 남기는 팀 회고 도구입니다.

## 구조 (멀티 에이전트)

```
엔딩 크레딧 (부모)
 ├─ 1. 기록 수집      : 회의록·채팅·문서 기록 모으기 (Teams·OneDrive 도구 + 지식 파일)
 ├─ 2. 기여 추적      : '발언 → 결정 → 결과물' 연결
 ├─ 3. 묻힌 기여 발굴 : 채택되지 않았거나 기록이 적은 기여 찾기
 └─ 4. 크레딧 작가    : "서사적 역할명 - 이름 (근거)" 크레딧과 엔딩 슬라이드
```

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `agents/` | 에이전트 5개의 설정과 지침 (Copilot Studio에 입력된 내용 그대로) |
| `demo/시연가이드.md` | 시연 순서, 입력할 질문, 정답표 |
| `demo/자료/` | 시연용 가상 조별과제 기록 10개 (모바일UX 5조, 「캠퍼스 야간 귀가 안전 앱」) |

- 질문할 때마다 제작자 계정의 Copilot 크레딧이 차감됩니다.

## 수정하는 방법 (중요)
GitHub와 Copilot Studio는 **자동으로 연결되어 있지 않습니다.** 여기서 고친 내용은 Copilot Studio에 직접 반영해야 에이전트가 바뀝니다.

**지침을 고칠 때**
1. `agents/`의 해당 파일에서 코드 블록 안의 지침을 수정합니다.
2. Copilot Studio → 해당 에이전트 → **안내** 칸의 내용을 지우고 수정한 지침을 붙여넣습니다.
3. **저장** → **게시** (자식 에이전트를 고쳤다면 부모도 다시 게시하는 것을 권장)

**시연 자료를 고칠 때**
1. `demo/자료/`의 .md 파일을 수정합니다.
2. Copilot Studio → **기록 수집 에이전트**와 **엔딩 크레딧(부모)** → 지식에서 기존 파일을 지우고 수정한 파일을 다시 올립니다.
3. **저장** → **게시**

## 알아둘 점
- 모든 에이전트는 **인증 없음**으로 설정되어 있습니다. Teams·OneDrive 도구는 제작자 계정 권한으로 실행되므로, 링크를 받은 사람도 제작자 계정의 Teams 채팅·OneDrive 파일을 조회할 수 있습니다. 시연 기간에만 공유하는 것을 권장합니다.
- 기획서에 있던 **정정 확인 카드(버튼)**, **PPT 파일 직접 생성**, **문서 버전 기록 자동 조회**는 아직 구현되지 않았습니다. 지금은 대화로 확인·정정을 받고, 슬라이드는 붙여넣을 텍스트와 서식 안내로 제공합니다.
- `demo/자료`의 인물과 내용은 모두 가상입니다.
